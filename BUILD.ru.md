# Сборка GeoStack

<!-- section:requirements -->
## Требования

Нужны Windows 11 x64, SDK .NET 10 из `global.json`, PowerShell и Python 3.10 или новее. Для WPF требуется Windows. Восстановление зависимостей использует NuGet; компиляция и обычный просмотр не отправляют медиафайлы. Используйте локальное окружение репозитория. Пакеты восстанавливаются в `.local/packages`; заранее созданный кэш NuGet в профиле пользователя не требуется. Не меняйте глобальную конфигурацию Git или защиту Windows.

<!-- section:commands -->
## Компиляция исходников

Выполните из корня репозитория:

```powershell
. ./scripts/environment.ps1
dotnet restore GeoStack.sln --ignore-failed-sources -p:NuGetAudit=false
dotnet build GeoStack.sln -c Release --no-restore
python scripts/check-public-tree.py --root . --report .local/public-audit.json
```

Исходники содержат компактные географические данные с закреплёнными версиями и уведомления. Для компиляции не нужны плотные мировые архивы и дополнительные карты городов. Детерминированные настройки компилятора сами по себе не доказывают побайтовую идентичность независимых сборок.

<!-- section:tests -->
## Медиаинструменты и тесты

Полный набор тестов требует отдельно полученных ExifTool/Perl и FFmpeg в `tools/ExifTool` и `tools/FFmpeg`, а также небольших синтетических или лицензированных образцов. Эти исполняемые файлы намеренно не публикуются здесь. Сохраняйте лицензии и проверяйте точное происхождение; не используйте личные файлы для тестов переноса.

```powershell
./scripts/test.ps1
```

При отсутствии образцов скрипты могут явно загрузить лицензированные материалы. Необязательная регенерация карт использует документированные Python-зависимости и закреплённые исходные данные; обычная сборка её не выполняет. Не создавайте большие атласы или тестовые медиатеки.

<!-- section:portable -->
## Локальные портативные сборки

После подготовки проверенных локальных инструментов:

```powershell
./scripts/build-portable.ps1 -OutputFolder dist/GeoStack-local-review-win-x64
```

Это только локальная самодостаточная Windows-сборка для проверки. Она не должна заменять рабочую версию. Требования к точным исходникам и уведомлениям бинарных зависимостей не закрыты: не загружайте результат и не публикуйте его через CI. См. [лицензионный статус](docs/REDISTRIBUTION_STATUS.ru.md).
