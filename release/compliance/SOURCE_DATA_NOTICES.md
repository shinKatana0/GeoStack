## Entire adapted data access

For ODbL section 4.6(a), the entire adapted databases are included in this source tree without extra charge or restrictions. Changes include selection, simplification, quantization, normalized hierarchy and indexing. Retain source identifiers, attribution and change records. `scripts/read-adapted-geography.py` reads all vector paths; SQLite/readable administrative fixtures remain paired. See [dataset inventory](../../docs/GEOGRAPHIC_DATASETS.md) for sources and formats. Full ODbL text is `release/compliance/licenses/ODbL-1.0.txt`; the official original is authoritative. No optional user-downloaded maps or native tools are included, and binary redistribution is not cleared.
