<!-- section:data -->
## Geographic data

Natural Earth data are public domain. OSM/Protomaps-derived compact roads and regional vectors are conservatively offered as adapted databases under ODbL-1.0, not merely raster works. Entire machine-readable adapted files, format reader, original notices and provenance accompany the source. Attribute OpenStreetMap contributors and retain source links.

Selected Overture/geoBoundaries `.gsgeo` test fixtures include ODbL, source-specific CC BY 4.0 and CC0 semantic metadata. Retain per-record source identifiers, original attribution, change disclosure and readable conversion inputs. Optional user-downloaded maps are not included. [Dataset inventory and access](docs/GEOGRAPHIC_DATASETS.md).

## Software and release blockers

Source projects reference .NET/Windows Desktop and test NuGet packages under their respective license terms; native runtime files are not in this tree. Windows fonts are referenced, not redistributed. The optional local media-tool license archive contains original third-party notices/patch material and retains its independent terms.

Binary redistribution remains blocked: the accepted FFmpeg GPL-3.0-or-later build lacks secured matching complete source/build materials; ExifTool/Perl native modules retain source/notice gaps. LGPL-labelled alternatives still need actual source, binary and regression verification. Public code signing is not established. Do not attach portable binaries to a source release. [Compliance matrix](docs/REDISTRIBUTION_STATUS.md).
