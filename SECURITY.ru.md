# Безопасность и конфиденциальность

<!-- section:reporting -->
## Безопасное сообщение о проблеме

Не размещайте учётные данные, оригинальные медиафайлы, GPS/EXIF, индексы и личные журналы в открытых задачах. Будущий репозиторий — shinKatana0/GeoStack; он ещё не опубликован, публичный контакт безопасности не настроен. Вымышленный адрес не указан. После создания одобренного репозитория используйте доступный в нём закрытый канал сообщения об уязвимости либо сначала запросите личный контакт, не раскрывая проблему публично.

<!-- section:privacy -->
## Границы работы приложения

Просмотр работает офлайн без телеметрии. Для загрузки требуется явное подтверждение; поставщик получает сведения о географических областях. Копирование сохраняет оригиналы. При переносе исходные файлы намеренно удаляются только после проверки и фиксации назначения; храните резервные копии и проверяйте журналы прерванных операций. Удаление из медиатеки никогда не удаляет файлы. Используйте проверенные источники пакетов карт и медиаинструментов.

<!-- section:limits -->
## Проверки и ограничения

Локальные проверки секретов, путей, языка и метаданных изображений ограничены и не дают математической гарантии конфиденциальности. Проверяйте находки, маскируя значения. При реальной утечке смену или отзыв учётных данных выполняет владелец; автоматически этого делать нельзя. Не отключайте Smart App Control, Defender и другую защиту. Неподписанная сборка может блокироваться; публикация исходников не заменяет подпись кода.
