# Branding provenance

<!-- section:source -->
## Original geometry

The vector master is `assets/branding/GeoStack.svg`: geometric photographic cards and a teal location pin, with no linked image or font. `scripts/generate-branding.ps1` renders the documented SVG subset using Python standard library only and generates PNG/ICO assets. The original SVG/ICO and generated GeoStack branding use Apache-2.0, Copyright 2026 shinKatana0. This is a project-artwork grant, not a claim over third-party map works.
