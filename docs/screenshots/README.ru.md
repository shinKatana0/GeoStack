# Снимки экрана

<!-- section:privacy -->
## Демонстрационные материалы

На снимках окна приложения показаны созданные для примера иллюстрации, тестовое видео и условные места съёмки. Личных фотоколлекций здесь нет. Интерфейс показан на английском; в GeoStack также есть русский язык. Подробные карты городов на этих снимках загружаются отдельно и не означают уличного покрытия всего мира.
