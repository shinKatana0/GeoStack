# Установка и портативное использование

<!-- section:scope -->
## Статус публикации исходников

Публичный ZIP с исполняемым приложением не одобрен. Эти инструкции относятся к локально собранному или отдельно одобренному портативному пакету для Windows 11 x64, а не к доступной загрузке. Бинарных медиаинструментов в этом дереве исходников нет; см. [BUILD](../BUILD.ru.md).

<!-- section:usage -->
## Использование и сохранение данных

Распакуйте пакет целиком в доступную для записи папку и запустите `GeoStack.exe`. Сохраняйте рядом необходимые инструменты, географические данные и уведомления. Самодостаточная сборка не требует установщика и системной .NET. Не заменяйте работающий исполняемый файл. При обновлении сохраняйте профиль данных, каталог карт, установленные пакеты, миниатюры и журналы копирования/переноса. Резервируйте предыдущий полный пакет отдельно от пользовательских данных.

Язык и тема выбираются в настройках; системный режим использует поддерживаемые системные значения с английским резервным языком. Для изолированного тестирования можно явно указать `--data <isolated-profile>`; не направляйте предварительную сборку на рабочие данные. Не ослабляйте защиту Windows ради неподписанного пакета.
