# Known limitations

<!-- section:coverage -->
## Maps and media

The global atlas is simplified geographic context, not a street-navigation map. Urban footprints show approximate historical built-up areas. Local detail, administrative boundaries and translated names depend on installed data. Text printed into raster maps does not change with the interface language.

Media support depends on the camera format, codec and local tools. Tested samples do not establish support for every RAW or video file. Detailed map downloads need an internet connection and a reachable provider; installed maps work offline.

<!-- section:safety -->
## Performance and file operations

Occasional pauses during window resizing remain unresolved; measurements include a 370 ms delay. This is a known limitation, not a fixed issue.

Copy is the default. Keep backups before moving valuable files. Interrupted transfers, failing hardware and every filesystem or power-loss scenario cannot be covered by a universal recovery guarantee. Review incomplete operations before continuing.

GeoStack-owned source and original branding use Apache-2.0, Copyright 2026 shinKatana0. Windows binary distribution has separate unresolved FFmpeg/Perl obligations. Unsigned builds may be blocked by Windows security policy. There is no Android application in this repository.
