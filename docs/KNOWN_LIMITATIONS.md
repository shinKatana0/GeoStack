# Known limitations

<!-- section:coverage -->
## Geography and formats

Global context is simplified and incomplete for street navigation; urban footprints are historical approximate extents. Regional detail, administrative containment and multilingual labels depend on installed data. Raster labels remain baked in. Codec/RAW support is sample-tested, not universal. Missing drives must not destroy indexed metadata. Detailed downloads require explicit confirmation and a reachable permitted provider.

<!-- section:safety -->
## Performance and release gates

Historical occasional Dispatcher/resize hesitation, including a measured 370 ms outlier, remains technical debt; owner visual acceptance does not relabel it PASS. No arbitrary-filesystem/power-loss guarantee is promised for move. Copy is the default; keep backups. Source-only publication awaits license/branding/public-identity approval. Portable binary redistribution remains blocked by exact FFmpeg/Perl obligations; unsigned Windows builds may be blocked by security policy. No Android application is included.
