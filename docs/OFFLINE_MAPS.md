# Offline maps and GPS browsing

<!-- section:layers -->
## Coverage layers

The always-on lightweight global fallback contains land/water, boundaries, populated places, historical urban footprints and selected generalized major roads. It is geographic context, not a worldwide street-navigation database. Installed regional context and detailed city packages add actual local geometry. Fallback remains beneath package boundaries. English/Russian labels exist only where verified translations or matching map variants are available; baked raster text cannot be relocalized.

<!-- section:download -->
## Download deliberately

Open Maps → Download Detailed Maps for My Library. Indexed GPS locations are grouped independently from visual marker clusters. The preview distinguishes actual installed tile/zoom coverage from missing context/detail. Review bounds, provider, attribution, detail, destination and size. Unknown source/installed sizes stay unknown; conservative upper bounds are labelled. Deselect unwanted regions and confirm before network activity.

Downloads use bounded Protomaps range acquisition and compatible local conversion. No public OSM tile-server scraping. Verified completed maps persist; cancellation removes unfinished work without discarding completed regions. Normal browsing is offline. Requests reveal chosen geographic areas, not media, filenames, EXIF or individual coordinate lists.

<!-- section:management -->
## Manage and navigate

Map Manager keeps catalogs and actual bounds. Do not assume a city's name means full city coverage. Pan/zoom, double-click media navigation, back history and off-screen indicators retain camera/geographic alignment. Visual maps do not supply Country/City containment: import administrative `.gsgeo` data separately. [Providers](MAP_DOWNLOAD_PROVIDERS.md) · [Data rights](GEOGRAPHIC_DATASETS.md).
