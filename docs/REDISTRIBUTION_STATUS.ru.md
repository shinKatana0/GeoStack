## Пакеты для Windows

Официальные сборки для Windows пока не распространяются. Невыполненные требования относятся к конкретным инструментам и данным в составе пакета и не зависят от лицензии собственного кода GeoStack.

| Компонент | Статус и недостающие материалы |
|---|---|
| FFmpeg GPL-3.0-or-later | BLOCKED: точные соответствующие исходники, патчи и инструкции сборки/установки. |
| Нативные модули ExifTool/Perl | BLOCKED: точные исходники и сведения о сборке, а также необходимые уведомления для Brotli, Win32::FindFile и других компонентов. |
| Географические данные | В бинарный пакет нужно отдельно включить обязательную атрибуцию и материалы для доступа к данным; для исходного дерева эти материалы уже приложены. |
| Подпись кода | Публичная подпись пока не настроена. Самоподписанный сертификат не является основанием для доверия публичной сборке. |

Даже замена с маркировкой LGPL требует проверки конкретного бинарного файла, исходников и условий распространения. Успешная локальная сборка сама по себе не разрешает распространение пакета.
