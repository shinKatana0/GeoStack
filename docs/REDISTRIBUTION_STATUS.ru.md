## Пакеты для Windows

Выбранный пакет Windows 0.5.5 RC4 опубликован как v0.5.5. Точный состав среды и сопровождающие архивы исходников и уведомлений заменяют прежние пробелы FFmpeg GPL и нативных модулей; это не разрешение распространять произвольные сборки инструментов. FFmpeg 9.0.1 использует LGPL-2.1-or-later с полными соответствующими исходниками и входами сборки. Для ExifTool/Perl сохранены условия стандартных объектов, собранных из исходников и разрешительных компонентов, точные уведомления и доступ к исходникам. Включены полные адаптированные базы ODbL, атрибуция и средства читаемого экспорта. Файлы не подписаны, доверенная подпись Authenticode не заявляется. Расширенный физический тест переноса между дисками для этой версии не проводился. См. [материалы Windows](WINDOWS_RELEASE.ru.md) и [точный состав](../release/dependencies.lock.json).
