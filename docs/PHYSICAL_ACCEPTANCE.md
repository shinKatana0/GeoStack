# Practical verification checklist

<!-- section:checks -->
## Use a synthetic profile

Use a new isolated profile and disposable media only. Verify folder/file import, additive repeat drops, GPS filters and multi-selection. Check catalog-only removal, restart/rescan persistence and explicit file reimport. Pan/zoom across map boundaries, switch themes and resize. Inspect media stacks, off-screen navigation and previews. Test copy and deliberate move into temporary destinations, verify SHA-256 and inspect recovery state. Never move personal originals during testing.

<!-- section:evidence -->
## Record what happened

Use PASS / FAIL / NOT_TESTED. Programmatic WPF captures and direct service tests are not physical Explorer-drag or mouse acceptance. Source compilation is not binary legal clearance. Leave unperformed cross-volume/device-failure cases unverified and retain independent backups.
