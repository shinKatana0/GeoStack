# Портативный выпуск Windows

<!-- section:download -->
## Состояние загрузки

GeoStack 0.5.5 для Windows 11 x64 подготовлен к публикации. Официальный пакет пока не опубликован. После объявления выпуска загрузите полный ZIP и контрольные суммы SHA-256 на [странице выпусков](https://github.com/shinKatana0/GeoStack/releases). Локальная папка разработки не является официальным выпуском.

<!-- section:install -->
## Установка и запуск

Распакуйте полный ZIP в новую папку с правом записи и запустите GeoStack.exe. Установщик и системная установка .NET 10 не нужны. Сохраняйте папки tools, geography, atlas, licenses и compliance вместе. Исполняемый файл не подписан: Windows может предупредить о нём или запретить запуск. Доверенная подпись Authenticode не заявляется; не отключайте защиту Windows.

Для первых проверок Copy to Location и Move to Location используйте отдельные тестовые файлы. Копирование сохраняет оригиналы. Перемещение удаляет исходники только после подтверждения, проверки и фиксации назначения. Предложения страны и города требуют административных данных нужного региона; отсутствие покрытия показывается явно. Загрузка дополнительных детальных карт требует разрешения.

<!-- section:materials -->
## Исходники и уведомления

Сохраняйте вместе приложение, контрольные суммы, GeoStack-0.5.5-ffmpeg-sources-RC4.zip и GeoStack-0.5.5-perl-notices-and-sources-RC4.zip. Приложение содержит уведомления Apache-2.0 для GeoStack, отдельные условия сторонних компонентов, географическую атрибуцию, полные включённые адаптированные базы ODbL и инструмент их чтения. Дополнительные карты сохраняют собственные условия. Инструкции доступа к стандартным объектам Perl указывают точный официальный архив Strawberry; архивы исходников и оригинальные уведомления обеспечивают остальные выбранные условия. См. [сторонние компоненты](../THIRD_PARTY_NOTICES.ru.md) и [точный состав среды](../release/dependencies.lock.json).

<!-- section:source -->
## Соответствие исходников

Исходный портативный бинарный пакет содержит идентификатор входных данных компиляции df4a9d7e4913db3f6eeb74045149ba2f9a40c8d6. Это архивный идентификатор сборки, а не коммит, импортированный в публичный репозиторий. Публичный тег выпуска обозначает соответствующий проверенный снимок исходников. Заголовки лицензий и окончания строк отличаются от исходных входных данных компиляции; единственная интеграция кода приложения исправляет проверку окна настроек. Отдельный GeoStack-0.5.5-RC4-build-sources.zip содержит точные исходные входные данные без частной истории Git. [Манифест выпуска](../release/windows-rc4.json) фиксирует архив и неизменённый бинарный пакет. Команды воспроизведения приведены в [BUILD](../BUILD.ru.md). Результат повторной сборки отделяется от RC4: отличающиеся хеши нужно записать, не подменяя исходный пакет.

Физическая проверка между дисками имеет статус NOT_TESTED по выбору владельца. Автоматические проверки отделены от физической приёмки. Скрипты сборки и проверки ничего не публикуют.
