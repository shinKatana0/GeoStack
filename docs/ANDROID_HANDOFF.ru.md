# Архитектурная передача для Android

<!-- section:reuse -->
## Повторно используемые принципы

Оцените географические модели, проверку GPS, пространственную кластеризацию, офлайн-проверку принадлежности, планирование назначений, форматы пакетов, индексирование медиа и контракты целостности/журнала. Повторное использование должно сохранять права на оригиналы и семантику ошибок; рефакторинг Windows ради предполагаемой переносимости не требуется.

<!-- section:replace -->
## Будущая платформенная работа

Потребуется заменить WPF, Windows-графику и декодеры, API процессов, файловые диалоги и перетаскивание из Проводника. Изучите MediaStore, Storage Access Framework, scoped storage, постоянные разрешения URI, доступ к оригиналам и согласие на удаление, жизненный цикл и фоновые ограничения. URI не равен пути настольной системы; перенос между поставщиками требует нового проверенного контракта. Проект Android и его функции не входят в этот выпуск.
